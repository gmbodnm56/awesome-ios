# Guidelines for Contributing

Thank you for contributing to Awesome iOS! Please take a moment to review these guidelines before submitting a pull request.

## Guidelines for Submitting Projects

1. **Alphabetical Order**: Make sure your entry is placed in alphabetical order under the appropriate category.
2. **Active Maintenance**: Ensure the project is maintained (recent commits within the last 6 months).
3. **Format**: Follow the formatting template:
   `* [LibraryName](https://github.com/user/repo) - Short description ending with a period.`
4. **SwiftUI / Swift Package Manager**: Mention SPM support or SwiftUI compatibility if applicable.
5. **No Self-Promotion without Quality**: Only submit projects that add clear value to the iOS developer community.

## Updating Existing Entries

- Fix broken links.
- Mark deprecated or archived projects appropriately.
- Keep descriptions updated as project scope evolves.

Thanks for helping keep this list curated and up to date!
